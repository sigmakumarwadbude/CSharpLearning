
# C# 14 and .NET 10 Learning Journey

A structured, project-based learning program covering C# 14 and .NET 10, from beginner to advanced.

## Learning Goals

- Master C# 14 fundamentals.
- Understand modern .NET architecture.
- Build ASP.NET Core REST APIs.
- Work with Entity Framework Core and SQL Server.
- Implement SOLID principles and design patterns.
- Build enterprise-grade full-stack applications.
- Learn Docker, CI/CD and cloud deployment.
